# CodeAlpha_UnemploymentAnalysisWithPython
## Unemployment rate analysis during covid-19.
- This dataset download from kaggle platfrom for my Internship on CodeAlpha.
- Unemployment in india: the lockdown shock and the slow recovery. we randomly choose Unemployment_Rate_upto_11_2020.csv.
- When I started working on the dataset, I realized that it needed to be cleaned.
- when i checked my data information, the first abnormality i noticed was unnecessary spaces between column names.
- The Date associated with it was not in the correct format.
- After the data information, I checked the data statistical summary.
- I renamed some columns to make them more meaningful, a column name should clearly indicate its purpose.
- I created some new columns based on the Date. Droped the column that ware not relevent to the work.
- Our data set did not contain missing values or duplicate values.
- we explored each column one by one and recorded the proceedings.
- The main objective of our analysis was to determine whether or not unemployment increased during COVID-19.
- I created some line plots for analysis, I create One of my favorite sunburst plot which showed the level of unemployment by zone and by state.
- To properly analyze Unemployment during covid-19, We divided the dataset into two parts, Pre-lockdown and Post-lockdown and then attempted to find answers to our questions.
- Our answer was Yes; unemployment rate increased during COVID-19.
- Pre-lockdown average unemployment rate: 9.23%.
- Peak monthly unemployment rate: 23.24%.
- Absolute increase: 14.01 percentage points
- Relative increase: 152%.
- Peak unemployment rate for each state by visualization.
- Higher unemployment rate in Puducherry 75.8%, Jharkhand 59.2%, Tamil Nadu 49.8%.
- Lower unemployment rate in Chhattisgarh 14.2%, Assam 11.1%, Meghalaya 10.0%.
- Pre-lockdown average LFPR (Estimated Labour Participation Rate (%)): 44.40%.
- Minimum LFPR during lockdown: 35.0%.
- Drop: 9.11 percentage points.
- As the Unemployment rate rose, labor force participation rate declined.
